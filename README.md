Deep Graph Network Analytics for Syndicated Fraud Detection
Project Overview

This project aims to identify organized fraud networks using graph analytics, community detection, and machine learning. Traditional rule-based fraud detection systems often struggle to identify complex fraud patterns involving multiple interconnected accounts, providers, devices, and synthetic identities.
The system models transactional relationships as a graph to detect suspicious communities, circular transaction patterns, and high-risk entities.

Objectives

Build a graph-based representation of transactional relationships.
Identify suspicious entities and interconnected fraud networks.
Apply community detection to discover potential fraud clusters.
Analyze network centrality and transaction patterns.
Predict fraud probability using machine learning.
Develop an interactive fraud visualization dashboard.
